Durable project knowledge for **mcp-tutorial**, kept in real files outside `CLAUDE.md`.

`CLAUDE.md` is loaded into every session and stays short. This vault is read on demand, grows
without budget pressure, and is meant to be edited, reviewed, and diffed like source.

## Conventions

- Every claim traces to a file someone actually read. No claims from priors about how projects
  "usually" look.
- Unknowns are written as `> TODO: <specific question>`. An honest gap beats a plausible invention.
- Secrets: env var **names and purposes only**. Never a value.
- Human-written prose wins over anything regenerated by a refresh.
